通达信 A 股语音播报 · Windows 使用说明

先安装 64 位 Python 3.11 或更新版本，安装时启用 Python Launcher（py）。
官方下载：https://www.python.org/downloads/windows/

把整个 ZIP 解压到一个文件夹。首次启动需要联网安装 Python 依赖。
安装包已包含浏览器界面，使用时无需安装 GitHub、Git 或 Node.js。

首次体验模拟行情
1. 双击 start.bat，等待浏览器自动打开。
2. 顶部会显示「模拟行情」和股票覆盖数量。
3. 点「测试中文语音」。如提示找不到中文语音，在 Windows 设置的
   「时间和语言 → 语音」中安装可用于桌面 SAPI 的中文语音。

使用自己的通达信实盘 Key
1. 登录 https://vip.tdx.com.cn/，进入「会员中心 → 积分和Key管理」。
2. 创建 Key 时只勾选「通达信数据服务」，然后复制 Key。
3. 关掉原有启动窗口，双击 setup-live.bat。在弹窗里按 Ctrl+V
   粘贴完整 Key，然后点确定。内容会遮挡，程序会先测试单股取数。
4. 配置完成后会启动网页，顶部显示「通达信实盘」。
   交易时段查看行情连接和覆盖率。以后双击 start.bat 即可。

如果要更换 Key，再运行一次 setup-live.bat。
如果要切回模拟，关闭启动窗口，用记事本打开项目里的 .env，
把 VOICE_SOURCE=tdx 改为 VOICE_SOURCE=mock，保存后双击 start.bat。
实盘接口可能消耗账号积分。Key 请只在自己的电脑上输入。
如提示 Key 被拒绝，检查 Key 是否启用、是否有「通达信数据服务」权限、
账户积分是否足够。请用商城的「复制」按钮获取完整 Key。
09:15–09:25 开盘集合竞价监控虚拟撮合价，09:30 起按成交行情播报。

播报优先级
个股异动 → 板块热点 → 板块资金 → 板块增仓 → 板块轮动 →
涨跌停 → 快速涨幅 → 打开涨停 → 打开跌停。
只有个股异动使用「教练教练请注意」。单独急涨归入快速涨幅。
热点板块播报当日涨幅前五只，并读出各股三、五、十日涨幅。
默认语速略快。可在 Dashboard 的参数设置中调整。
